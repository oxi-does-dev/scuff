# scuff

свой формат сжатия, `.scf` файлы. на большинстве файлов лучше zip

как пользоваться:
```
scuff c input [out.scf]   # сжать (файл или папку)
scuff d input.scf [output] # распаковать
```

папки пакуются в один .scf вместе со структурой (пустые папки тоже сохраняются,
симлинки скипаются), обратно распаковываются в папку.

сборка: `cargo build --release`, бинарь в `target/release/scuff-rs`.

что внутри: lz77 с окном 256кб и матчами до 4096, потом оптимальный парсинг через дп
(несколько проходов с разными ценами, беру лучший), хаффман по блокам, блоки режутся
адаптивно где выгодно. есть ещё fixed таблицы и stored для несжимаемого. жмётся в потоках.

замеры против `zip -9`:

| файл | scuff | zip |
|---|---|---|
| dataset.jsonl 217кб | 14кб | 15.5кб |
| периодика 160кб | 146б | 422б |
| шум 100кб | 100020 | 100186 |
| мелкий код ~20-40кб | проигрыш ~7% | выигрыш |

код жмётся чуть хуже, там zlib со своими микроблоками шустрее соображает, лень было догонять.
жмёт меньше секунды на 200кб (16 потоков), распаковка миллисекунды.

формат: `SCUFF\x04` + длина u32 + crc32 + биты. дальше блоки: fin бит + тип 2 бита
(00 сырые байты, 01 fixed, 10 dynamic) + дерево если dynamic + токены + end.
